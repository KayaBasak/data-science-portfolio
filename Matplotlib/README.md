# Matplotlib: Data Visualization in Python

This folder contains practical examples of data visualization using **Matplotlib**, one of Python's core libraries for creating charts and exploring data.

Through hands-on examples and a real-world Spotify dataset, I explore different plot types, learn how to choose the right visualization for a given question, and practice customizing charts to communicate insights effectively.

## Contents

### 1. Matplotlib Explained: Choosing the Right Plot and Creating Your First Visualizations

An introduction to data visualization with Matplotlib, covering six common plot types and when to use them.

- Line charts
- Bar charts
- Histograms
- Scatter plots
- Box plots
- Pie charts

**Article:** [Read on Medium](https://medium.com/@bskky001/matplotlib-explained-choosing-the-right-plot-and-creating-your-first-visualizations-d3a4c0d90774)

### 2. Matplotlib Tutorial: Customizing Charts With a Real Spotify Dataset

A hands-on tutorial on customizing Matplotlib visualizations, including figure size, colors, markers, titles, axis labels, gridlines, transparency, and legends.

**Article:** [Read on Medium]()

## Dataset

The tutorials use a Spotify dataset containing track information and audio features such as popularity, duration, energy, danceability, speechiness, and genre.
